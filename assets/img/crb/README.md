# Photos de chantier CRB

Déposez ici les vraies photos de chantier CRB pour remplacer les photos Unsplash par défaut.

## Instructions
1. Ajoutez vos photos dans ce dossier.
2. Modifiez le script `scripts/optimize-images.mjs` pour cibler vos nouvelles photos ou modifiez le HTML directement.
3. Exécutez `node scripts/optimize-images.mjs` depuis la racine du projet pour générer les formats optimisés (WebP, JPG) et les différentes tailles.
4. Mettez à jour les liens d'images dans `index.html`.
